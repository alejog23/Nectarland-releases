# 🌿 Nectarland

¡Bienvenido/a al repositorio oficial de **Nectarland**! 🚀  
Un entorno de escritorio e interfaz modular para Windows diseñado para ser estético, rápido y completamente personalizable. Con Nectarland podés llevar la personalización de tu sistema al siguiente nivel.

---

### ✨ Características Principales
* **Nectar Dock:** Una barra de aplicaciones fluida, inteligente y animada con soporte para auto-hide.
* **Nectar Notch:** Un centro de control elegante en la parte superior de tu pantalla para accesos rápidos.
* **Color Inteligente:** Sincronización automática con el color de acento nativo de tu sistema Windows.
* **Ecosistema Modular:** Ajustes independientes y sincronizados en tiempo real mediante Tauri v2.

---

### 🛠️ Tecnologías Usadas
Nectarland está construido sobre un ecosistema moderno y de altísimo rendimiento:
* **Frontend:** React + TypeScript + Framer Motion (para animaciones ultra fluidas).
* **Backend nativo:** Rust + Tauri v2 (máxima velocidad, mínimo consumo de RAM).
* **Gestor de paquetes:** Bun / Cargo.

---

### 🚀 Cómo Empezar (Desarrollo Local)

Si querés clonar el repositorio y correrlo en tu máquina, asegurate de tener instalado [Bun](https://bun.sh) y [Rust](https://rust-lang.org). Luego, ejecutá:

1. **Clonar el proyecto:**
   ```bash
   git clone https://github.com
   cd Nectarland
   ```

2. **Instalar dependencias y correr en modo dev:**
   ```bash
   bun install
   bun run dev
   ```

### 🤝 ¿Querés colaborar? (¡Sumate a Open Code!)
Este es un proyecto impulsado por la comunidad a través de la iniciativa **Open Code**. ¡Toda ayuda es bienvenida! 

Si encontrás un bug (como problemas con el foco del teclado 😅) o querés proponer una mejora (como nuevos modos de color):
1. Abrí un **Issue** explicando tu idea.
2. Hacé un **Fork** del repositorio.
3. Creá tu rama de función (`git checkout -b feature/NuevaFuncion`).
4. Enviá un **Pull Request**.
